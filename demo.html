The V14 Algorithm

XOR + channel-swap + seeded PRNG
STEP 01
Channel Swap
R moves to B slot, G to R slot, B to G slot. A cyclic permutation that destroys colour relationships before XOR.
STEP 02
XOR Encrypt
Each channel XORed with an 8-bit key from the PRNG. XOR is exactly self-inverse: a ^ k ^ k = a always.
STEP 03
Seeded PRNG
Keys come from xorshift32, initialised with a 32-bit secret seed. 4 values per pixel — one discarded to keep the state aligned.
Encrypt
function encrypt(pixels, seed) {
  const d   = new Uint8ClampedArray(pixels);
  const rng = seededPRNG(seed);
  for (let i = 0; i < d.length; i += 4) {
    const kr = rng(), kg = rng(), kb = rng();
    rng(); // 4th consumed, keeps alignment
    const r = pixels[i], g = pixels[i+1],
          b = pixels[i+2];
    d[i]   = g ^ kr; // R slot ← G XOR kr
    d[i+1] = b ^ kg; // G slot ← B XOR kg
    d[i+2] = r ^ kb; // B slot ← R XOR kb
    d[i+3] = 255;    // alpha always opaque
  }
  return d;
}
Decrypt — identical structure
function decrypt(pixels, seed) {
  const d   = new Uint8ClampedArray(pixels);
  const rng = seededPRNG(seed);
  for (let i = 0; i < d.length; i += 4) {
    const kr = rng(), kg = rng(), kb = rng();
    rng();
    // XOR undoes XOR exactly
    const origG = pixels[i]   ^ kr;
    const origB = pixels[i+1] ^ kg;
    const origR = pixels[i+2] ^ kb;
    // un-swap channels
    d[i]   = origR;
    d[i+1] = origG;
    d[i+2] = origB;
    d[i+3] = 255;
  }
  return d;
}

Version history

v0.1.0
Proof of concept
V10 algorithm — floating-point arithmetic. 54–58% channel error. Demonstrated the concept; proved pixel-level encryption was feasible.
v0.4.0
Alpha key storage fix
V11 — stored key in alpha channel directly. Reduced errors to 18%, identified root cause: any irreversible operation with clamping cannot be undone.
v0.5.0
XOR + channel scramble
V12 and V13 — switched to XOR (exactly self-inverse), added cyclic channel swap. First 0% error versions. No seed — key was deterministic from position.
v1.0.0
Production — Seeded PRNG
V14 — replaced position-based key with xorshift32 seeded PRNG. Added pixel-shield.js standalone library, this demo, and full documentation.
